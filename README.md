# 🚀 Prompt Tutor Academy

> An interactive, AI-driven educational platform designed to teach beginners and engineers how to craft, evaluate, score, and execute world-class prompts for LLMs and Generative Visual Models.

---

## 🌟 Key Features

1. **Personalized Welcome & Onboarding Experience**
   - Asks for the user's name or callsign with live, real-time personalized greetings.
   - Pinned **Founders & Team Credits** on the bottom right of the page:
     - **Founder:** Shivprakash Shukla
     - **Team Members:** Subhiksha Singh, Saniya Pandey, Shiva Shukla
   - **Rocket Launch Blast-Off Animation**: Clicking "Continue" triggers an epic sound-synthesized rocket countdown, thruster ignition, rumble, screen shake, and hyperspace warp flash transition into the academy workspace.

2. **AI Prompt Coach & Multi-Dimensional Scorer**
   - Enter any basic prompt (e.g., `"make a calculator"`).
   - Real-time **Overall Score (0-100)** with color-coded gauge and verdict badges.
   - 4-Dimensional Metric Breakdown:
     - 🎯 **Clarity & Specificity**
     - 🎭 **Persona & Role Definition**
     - ⚙️ **Constraints, Stack & Validations**
     - 📋 **Output Guidance & Edge Cases**
   - Constructive AI Diagnostic Critique detailing missing elements and best practices.

3. **Intelligent "Better Prompt" Generator**
   - Formulates a production-grade, highly specific prompt adhering to the **RTF (Role, Task, Format)** and **CLEAR** frameworks.
   - For example, upgrades `"make a calculator"` into an enterprise-ready spec with modular architecture, division-by-zero validation, consecutive operator locks, dark-mode CSS, and keyboard numpad event listeners.

4. **Side-by-Side Dual Output Execution**
   - **User's Raw Prompt Output:** Demonstrates what a typical AI outputs for vague prompts (barebones, unhandled exceptions, zero UI).
   - **AI Better Prompt Output:** Demonstrates the comprehensive, production-ready deliverable with robust error handling, typing, and comments.
   - **Live Interactive Preview:** Run and interact with the resulting code (e.g. interactive calculator) directly inside the browser!

5. **Generative Visuals & Image Prompt Studio**
   - Input basic image concepts (e.g., `"a cat in space"`).
   - Enhances the prompt with photographic focal length (35mm / 85mm f/1.4), volumetric atmosphere, lighting, and octane render engines.
   - **Dual Visual Generation via Pollinations AI:** Generates and compares the user's basic image vs the AI-enhanced masterpiece side-by-side in real-time.

6. **Prompt Formulas & Challenge Arena**
   - Reference guide for **RTF**, **CLEAR**, **Chain-of-Thought (CoT)**, and **Negative Constraints**.
   - Hands-on challenge drills to upgrade vague prompts into 85+ score master prompts.

---

## 💻 How to Run

### Method 1: Python Flask Server (Recommended)
```bash
python app.py
```
Open your browser and navigate to: **`http://localhost:5000`**

### Method 2: Direct Browser Launch (Zero-Setup)
Double-click `index.html` in Windows Explorer or open it in any modern browser (Chrome, Edge, Firefox). The entire AI intelligence engine, audio synthesizer, and image generator run natively in the browser without requiring a server!
