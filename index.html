          📚 Architecture & Frameworks
          
    The Prompt Engineer's Formula Handbook
    
          
    
            Top prompting frameworks used by AI researchers, prompt engineers, and developers worldwide to achieve consistent, hallucination-free outputs.
          
    
        
    

        
    
          
          
    
            
    
              
    🎯
    
              
    
                Foundation Framework
                
    The RTF Framework
    
              
    
            
    
            
    The simplest and highest-leverage formula for 90% of everyday AI tasks.
    
            
    
              
    
                R = Role
                "Act as a Principal Python Cloud Architect"
              
    
              
    
                T = Task
                "Design an automated data ingestion pipeline with retries"
              
    
              
    
                F = Format
                "Provide as a Markdown table comparing 3 AWS services with pros/cons"
              
    
            
    
            
    
              Prompt: "Act as [Role]. I need you to [Task]. Present the output in [Format]."
            
    
          
    

          
          
    
            
    
              
    ⚡
    
              
    
                Advanced Engineering
                
    The CLEAR Model
    
              
    
            
    
            
    Engineered for complex software features, technical docs, and business strategy.
    
            
    
              
    CContext: Background situation & goals
    
              
    LLimitations: Strict constraints & boundaries
    
              
    EExamples: 1 or 2 reference inputs/outputs
    
              
    AAction: The exact verb of what to produce
    
              
    RReview: Self-critique before finalizing
    
            
    
            
    
              "Review your draft against performance benchmarks before replying."
            
    
          
    

          
          
    
            
    
              
    🧠
    
              
    
                Reasoning Accelerant
                
    Chain-of-Thought (CoT)
    
              
    
            
    
            
    Dramatically decreases math and logic hallucinations by forcing step-by-step deduction.
    
            
    
              
    Step 1"Think step-by-step through the logic first."
    
              
    Step 2"State your intermediate reasoning in <thinking> tags."
    
              
    Step 3"Provide the final verified answer at the end."
    
            
    
            
    
              "Before writing any code, draft the algorithm steps and identify edge cases."
            
    
          
    

          
          
    
            
    
              
    🛡️
    
              
    
                Guardrail Control
                
    Negative Constraints
    
              
    
            
    
            
    Eliminates AI fluff, conversational filler, and unwanted libraries.
    
            
    
              
    Rule 1"Do NOT use external npm packages; use native APIs only."
    
              
    Rule 2"Do NOT include conversational preambles like 'Sure! Here is...'."
    
              
    Rule 3"Never use placeholder '// write code here' comments."
    
            
    
            
    
              "Negative constraints cut through token waste and ensure production ready code."
